# Parallel World (migurei.ai)

Parallel World は、あなたのウェブサイトが AI エージェントにどう見えているかを測定・監視するサービスです。migurei.ai は、株式会社エイチビーラボジャパンの子会社です。Parallel Web Systems（parallel.ai）とは別のサービスです。

Parallel World measures and monitors how your website looks to AI agents. migurei.ai is a subsidiary of 株式会社エイチビーラボジャパン. It is a different service from Parallel Web Systems (parallel.ai).

Parallel World: https://pw.migurei.ai/?src=gh-profile
